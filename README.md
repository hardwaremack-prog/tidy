# Tidy

A spreadsheet that explains itself. It runs in the browser and is part of the [Tidy suite](https://github.com/hardwaremack-prog/tidy-suite) with Neat and Spruce.

![Tidy screenshot](<Tidy - screenshot.png>)

## What's in it

- A full spreadsheet grid with Home, Insert, Data and View ribbon tabs
- Formulas like `=SUM`, `=IF` and many more, with full undo and redo
- The **Sidekick** panel explains the formula in the selected cell in plain English and has a clickable function cheat sheet
- Fonts, alignment, borders, number formats and freeze panes
- Multiple sheets you can add, duplicate and rename
- Import and export files, find and replace, and printing
- Saves on its own in your browser, so it picks up where you left off

## Run it

Download `tidy-final-b34.html` and open it in your web browser. No install, no account, nothing to set up.

The full guide is in `tidy_manual.pdf`.
